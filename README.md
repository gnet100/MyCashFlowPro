## 📋 API Endpoints - קטגוריות

### GET `/categories` - דף הניהול
דף HTML מלא עם עץ קטגוריות

### GET `/categories/api/list` - רשימה
```json
{
  "success": true,
  "categories": [...]
}
```

### GET `/categories/api/tree` - עץ היררכי
```json
{
  "success": true,
  "tree": [...]
}
```

### GET `/categories/api/get/<id>` - פרטי קטגוריה
```json
{
  "success": true,
  "category": {
    "id": 5,
    "name": "מזון",
    "parent_id": 1,
    "level": 2,
    "full_path": "הוצאות > מזון",
    "transaction_count": 15
  }
}
```

### POST `/categories/api/add` - הוספה
```json
{
  "name": "סופרמרקט",
  "parent_id": 5
}
→ {"success": true, "category_id": 10}
```

### PUT `/categories/api/update/<id>` - עדכון
```json
{
  "name": "סופר עדכני"
}
→ {"success": true}
```

### DELETE `/categories/api/delete/<id>` - מחיקה
```
→ {"success": true}
או
→ {"success": false, "error": "לא ניתן למחוק..."}
```
