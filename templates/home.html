📖 הליך התחברות והפעלת המערכת ▼

🖥️ התקנה והפעלה ראשונית במחשב חדש

שלב 1: הורדת הקבצים
  1. הורד את הקובץ: financial-manager-M3-P1-COMPLETE-WITH-DOCS.zip
  2. חלץ את הקבצים למיקום קבוע, למשל: C:\Users\[שם_משתמש]\Documents\financial-manager
שלב 2: התקנת Python (אם לא מותקן)
  1. גש לאתר: https://www.python.org/downloads/
  2. הורד את Python 3.8 ומעלה (מומלץ: Python 3.11 או 3.12)
  3. חשוב מאוד: במהלך ההתקנה, סמן את האפשרות Add Python to PATH
  4. לחץ "Install Now" והמתן להתקנה
  5. לאחר ההתקנה, פתח PowerShell או CMD ובדוק: python --version
שלב 3: התקנת תלויות
  1. פתח PowerShell או CMD
  2. נווט לתיקיית המערכת: cd C:\Users\[שם_משתמש]\Documents\financial-manager
  3. התקן את התלויות: pip install -r requirements.txt
  4. במידה ויש שגיאת הרשאות, הוסף --user: pip install --user -r requirements.txt
שלב 4: הפעלה ראשונה
  1. וודא שאתה בתיקיית המערכת
  2. הרץ את השרת:
    • Windows: לחיצה כפולה על start_simple.bat
    • או ידנית: python app.py
  3. אמור להופיע הודעה: "Running on http://127.0.0.1:5000"
  4. פתח דפדפן ונווט ל: http://localhost:5000
  5. טען נתוני דוגמה: לחץ על "📊 טען נתוני דוגמה" כדי להתחיל לעבוד עם המערכת

🚀 הפעלה רגילה (מערכת מותקנת)

דרך 1: הפעלה מהירה (Windows)
  1. נווט לתיקיית המערכת ב-File Explorer
  2. לחיצה כפולה על הקובץ: start_simple.bat
  3. חלון טרמינל שחור ייפתח - אל תסגור אותו!
  4. כשתראה "Running on http://127.0.0.1:5000" - המערכת רצה
  5. פתח דפדפן ב: http://localhost:5000
דרך 2: הפעלה דרך PowerShell
  1. פתח PowerShell
  2. נווט לתיקייה: cd C:\Users\[שם_משתמש]\Documents\financial-manager
  3. הרץ: .\start_simple.bat או python app.py
  4. פתח דפדפן ב: http://localhost:5000
דרך 3: הפעלה דרך CMD
  1. לחץ Win + R
  2. הקלד: cmd ולחץ Enter
  3. נווט לתיקייה: cd C:\Users\[שם_משתמש]\Documents\financial-manager
  4. הרץ: python app.py
  5. פתח דפדפן ב: http://localhost:5000

🐛 פתרון בעיות נפוצות

בעיה: "Python was not found"
  • פתרון 1: התקן Python (ראה למעלה) וודא שסימנת "Add to PATH"
  • פתרון 2: הרץ עם נתיב מלא: C:\Python311\python.exe app.py
  • פתרון 3: הפעל מחדש את המחשב אחרי התקנת Python
בעיה: "Port 5000 is already in use"
  • פתרון 1: סגור תוכניות אחרות שעשויות להשתמש בPort 5000
  • פתרון 2: ערוך את app.py ושנה את השורה האחרונה ל: app.run(debug=True, port=5001)
  • פתרון 3: הרוג את התהליך הקודם:
    • Windows: taskkill /F /IM python.exe
בעיה: "ModuleNotFoundError: No module named 'flask'"
  • פתרון: התקן תלויות: pip install -r requirements.txt
  • אם לא עובד: pip install Flask==3.0.0
בעיה: הדפדפן לא פותח את המערכת
  • פתרון 1: נסה http://127.0.0.1:5000 במקום localhost
  • פתרון 2: בדוק חומת אש (Firewall) - אשר גישה לPython
  • פתרון 3: נסה דפדפן אחר (Chrome, Firefox, Edge)
בעיה: השרת נעצר לפתע
  • בדוק הודעות שגיאה בטרמינל
  • ודא שלא סגרת את החלון השחור בטעות
  • הפעל מחדש: python app.py

  • מיקום מסד הנתונים: data\financial.db - אל תמחק קובץ זה!
  • גיבוי: מומלץ לגבות את הקובץ financial.db מדי פעם
  • עצירת השרת: לחץ Ctrl + C בחלון השחור
  • נתיבי מערכת חשובים:

    • Python: נמצא בדרך כלל ב-C:\Python311\ או C:\Users\[שם]\AppData\Local\Programs\Python\
  • מסמכי עזרה: קרא את README.md ו-NEXT-SESSION-GUIDE.md
